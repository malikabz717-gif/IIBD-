# Кейс-задача №1

## Условие
Дан одномерный массив A размерности N.  
Найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами.

## Язык программирования
C++

## Описание решения
Программа:
1. Считывает количество элементов массива `N`;
2. Считывает элементы массива `A`;
3. Находит индексы максимального и минимального элементов массива;
4. Определяет границы участка между максимальным и минимальным элементами;
5. Вычисляет сумму отрицательных элементов, расположенных между ними;
6. Выводит результат на экран.

## Пример работы программы

Введите количество элементов массива N: 7  
Введите элементы массива: 1 8 -3 -2 4 -6 0  

Результат:  
Сумма отрицательных элементов между максимальным и минимальным: -5
