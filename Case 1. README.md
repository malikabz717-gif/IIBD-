# Кейс-задача №1

## Условие
Дан одномерный массив A размерности N.  
Найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами.

## Описание решения
Программа:
1. Считывает количество элементов массива `N`;
2. Считывает элементы массива;
3. Находит индексы максимального и минимального элементов;
4. Определяет участок массива между ними;
5. Вычисляет сумму отрицательных элементов, находящихся между максимальным и минимальным.

## Пример работы программы

Введите количество элементов массива N: 7  
Введите элементы массива через пробел: 1 8 -3 -2 4 -6 0  

Результат:  
Сумма отрицательных элементов между максимальным и минимальным: -5
