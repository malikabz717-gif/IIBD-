# Кейс-задача №4

## Тема проекта

WEB-приложение "Tourism Orders" для учета заказов туров.

## Описание

В рамках кейс-задачи было разработано учебное WEB-приложение на **Delphi 10.2** с использованием WEB-архитектуры.

Приложение предназначено для отображения информации о заказах туров.  
WEB-приложение предполагает размещение на **MS Internet Information Server (IIS)**.  
База данных для приложения создана в **MS SQL Server**.

Проект демонстрирует основные принципы WEB-архитектуры:

- получение запроса от пользователя через браузер;
- обработку запроса на серверной стороне;
- подключение к базе данных;
- формирование HTML-страницы с результатами.

## Используемые технологии

- Delphi 10.2
- MS Internet Information Server (IIS)
- MS SQL Server
- SQL
- FireDAC

## Структура базы данных

База данных "TourismOrdersDB" включает следующие таблицы:

- "Clients" — клиенты;
- "Tours" — туры;
- "Services" — дополнительные услуги;
- "PaymentMethods" — способы оплаты;
- "Orders" — заказы туров.

Для всех таблиц созданы первичные ключи.  
В таблице "Orders" реализованы внешние ключи для связи со справочными таблицами:

- "ClientID" → "Clients(ClientID)";
- "TourID" → "Tours(TourID)";
- "ServiceID` → `Services(ServiceID)";
- "PaymentMethodID" → "PaymentMethods(PaymentMethodID)".

Файл "database.sql" содержит SQL-скрипт создания базы данных, таблиц, связей и тестовых данных.

## Работа с базой данных

В файле `WebModuleUnit.pas` реализовано подключение к базе данных MS SQL Server `TourismOrdersDB` с использованием FireDAC.

WEB-приложение выполняет SQL-запрос к таблицам:

- Orders;
- Clients;
- Tours;
- Services;
- PaymentMethods.

После получения данных приложение формирует HTML-страницу со списком заказов туров.

При необходимости в параметрах подключения можно изменить значение сервера, например на `localhost` или `.\SQLEXPRESS`.

## Назначение приложения

WEB-приложение может использоваться туристической компанией для учета заказов клиентов, выбранных туров, дополнительных услуг, способов оплаты и итоговой суммы заказа.

В учебной версии приложение отображает список заказов в виде HTML-таблицы.

При дальнейшем развитии проекта можно добавить:

- создание новых заказов;
- редактирование данных;
- удаление заказов;
- поиск и фильтрацию;
- авторизацию пользователей;
- разграничение прав доступа.
